# Assets — Taskmarket Live Market Visualizer

All source artwork/fonts come from `brand-kit/` (Taskmarket brand kit,
`0-TASKMARKET-BRAND-KIT.md`). Nothing in `brand-kit/` was modified
(verified: `git status` clean inside `brand-kit/`). No network calls were
made; no files were re-downloaded.

Brand tokens used throughout: ground `#12100E`, maroon `#3A1420`,
panel `#221E1A`, line `#453E37`, cream `#EFE9E2`, paper `#FFF6E8`,
muted `#B0A79D`, magenta `#E74079` (accent only — one word per piece,
never a background), salmon `#D9A097`. No banned words or imagery are
used anywhere in these assets.

`LATIN=U+0000-00FF,U+0131,U+0152-0153,U+02BB-02BC,U+02C6,U+02DA,U+02DC,U+0300-036F,U+2000-206F,U+2074,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD`):

```sh
python3 -m fontTools.subset brand-kit/InterTight-Variable.ttf \
  --output-file=public/fonts/InterTight-Variable.woff2 --flavor=woff2 \
  --unicodes="$LATIN" --layout-features='kern,liga,tnum' \
  --no-hinting --desubroutinize
python3 -m fontTools.varLib.instancer public/fonts/InterTight-Variable.woff2 \
  wght=400:700 --update-name-table -o public/fonts/InterTight-Variable.woff2
python3 -m fontTools.subset brand-kit/InstrumentSerif-Regular.ttf \
  --output-file=public/fonts/InstrumentSerif-Regular.woff2 --flavor=woff2 \
  --unicodes="$LATIN" --layout-features='kern,liga' --no-hinting --desubroutinize
python3 -m fontTools.subset brand-kit/InstrumentSerif-Italic.ttf \
  --output-file=public/fonts/InstrumentSerif-Italic.woff2 --flavor=woff2 \
  --unicodes="$LATIN" --layout-features='kern,liga' --no-hinting --desubroutinize
```

### Running the generator

```sh
python3 scripts/og.py            # from the project root; reads data/dashboard.json
python3 scripts/og.py --data /path/to/dashboard.json --out-dir /tmp/out
```

Deterministic: the same input file produces byte-identical PNGs
(verified by re-running and comparing md5). Missing `data/dashboard.json`
exits 2 with a clear error; a missing field omits that stat instead of
inventing a number. **Re-run after every `fetch.mjs` refresh** — the OG
images are a snapshot of the data file at generation time.

### Data-shape note (important)

The brief's schema showed top-level `headline` / `flow` / `posters`.
The real `data/dashboard.json` (written by `scripts/fetch.mjs`) nests
them per chain: `chains.<id>.headline`, `chains.<id>.flow`,
`chains.<id>.postersPerWeek`, `chains.<id>.topPosters`. `og.py`
handles **both**: top-level keys win when present, otherwise it reads
the chains. Two deliberate choices, documented in the script:

- **Headline/flow are never summed across chains.** The API returns
  platform-wide figures on each chain (verified: 4217 and 8453 agree
  exactly on every field the cards use), so the script reads one chain
  (Base 8453 first, then Tempo 4217). Summing would double-count.
- **Posters are chain-specific**, so `og-posters.png` uses the busier
  chain (most distinct posters this week — Tempo 4217 here, 15 vs 2)
  and its tag reads `POSTERS · TEMPO` so the chain is explicit. The top
  poster shows the API-returned display name when present, otherwise a
  truncated address; no names are guessed.
